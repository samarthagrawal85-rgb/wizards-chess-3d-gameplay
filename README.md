# ♟️ Wizard's Chess 3D — Gothic Cathedral Edition

Welcome to **Wizard's Chess 3D**, an immersive 3D chess game featuring a gothic cathedral-inspired design.

## 🎮 About the Game

Play chess in a dramatic 3D environment. Challenge the computer or play with a friend on the same device.

## ✨ Features

- 3D chessboard and gothic-inspired chess pieces
- Play against AI
- Local two-player mode
- Legal chess moves and captures
- Pawn promotion, castling, and checkmate detection
- 3D camera controls, rotation, and zoom
- Animated moves and sound effects
- Move history and game reset

## 🚀 How to Play

1. Open the website in a modern browser.
2. Choose AI mode or local two-player mode.
3. Select a chess piece.
4. Select a highlighted destination to move it.
5. Try to checkmate your opponent!
